# AbroadPedia

**Dream destinations. Grounded decisions.** Before you pay for education, check AbroadPedia.

An interactive prototype: scroll to fly a paper plane from Kathmandu to New Delhi, Dubai, Sydney and New York.
Each stop introduces one product pillar, and the working sections below the flight include:

- **EduWiki:** search and filters
- **Student Reality Check:** six-dimension reviews and a moderation queue
- **Compare Lab:** up to four options side by side
- **Opportunity Radar** and the **Daily Abroad Brief**
- **Bid Arena:** a clearly labelled, simulated sponsored section
- **My Abroad Journey:** a journey tracker

## Data honesty

Provider profiles marked **Demo profile** are placeholders, not real businesses. Universities and scholarship
programmes are real and link to their official websites. Fees, deadlines and eligibility are shown as
"Not yet verified" until they have been checked at the source. No payments are processed.

## Run locally

```bash
npm install
npm run dev
```

Built with Next.js, TypeScript and three.js. The 3D world is procedural and uses no external assets.
